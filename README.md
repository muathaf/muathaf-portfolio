## Overview
This repository contains the source code for a highly optimized, modern web application built with **Astro**. 

While my primary focus is Cloud Engineering and MLOps, I built this frontend architecture to demonstrate my ability to manage component-based frameworks, utilize NPM package management, and prepare modern web apps for edge deployments.

## 🏗️ Tech Stack
* **Framework:** Astro (Zero-JS frontend architecture)
* **Styling:** CSS / Tailwind
* **Package Management:** NPM
* **Version Control:** Git

## 🚀 Running Locally
If you want to spin this up on your local machine:
```bash
# Install dependencies

# Run the local development server
